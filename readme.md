# 🚀 PRODIGY_FS-02

A Full-Stack Employee Management System built using Node.js, Express, and MongoDB.

This project allows management of employees, departments, authentication, and file uploads.

---

## 📌 Project Overview

PRODIGY_FS-02 is a full-stack web application that includes:

- 🔐 User Authentication
- 👨‍💼 Employee Management
- 🏢 Department Management
- 📊 Dashboard APIs
- 📁 Image Upload Support
- 🌐 RESTful Backend Architecture

---

## 🛠️ Tech Stack

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Multer (for file uploads)
- Bcrypt (for password hashing)

### Frontend
- React.js (if used)
- Axios
- React Router

---

📡 API Features

. POST /api/auth/login

. POST /api/auth/register

. GET /api/employee

. POST /api/employee

. GET /api/department
